# MacDown Lite

一个**纯阅读**的 Markdown 查看器 —— Apple 芯片（arm64）原生运行，不再依赖 Rosetta。

> 渲染内核沿用 MacDown 的 [hoedown](https://github.com/hoedown/hoedown)，CSS 主题也取自 MacDown。

---

## 怎么用

1. **文件 → 打开…**（`⌘O`）选择 `.md` 文件
2. 或者直接把文件**拖进窗口**
3. 在 Finder 里**右键 → 打开方式 → MacDown Lite**（可设为默认）

打开后会一直盯着文件：**你在别的编辑器里保存，这边自动刷新**。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开文件 | `⌘O` |
| 查找… | `⌘F` |
| 查找下一个 / 上一个 | `⌘G` / `⇧⌘G` |
| 重新载入 | `⌘R` |
| 放大 / 缩小 | `⌘+` / `⌘-` |
| 实际大小 | `⌘0` |
| 打印 | `⌘P` |
| 导出 PDF / Word | **文件 → 导出为** |
| 全屏 | `⌃⌘F` |

## 导出

**文件 → 导出为** 可以直接导出两种格式：

- **PDF** —— A4 分页，页边距与屏幕上的纸张一致；生成的是**真正的文字 PDF**（可选中、可搜索），不是截图。
- **Word 文档 (.docx)** —— 真正的 OOXML 文件，Word / WPS / Pages 都能直接打开编辑。标题、正文、首行缩进、列表编号、表格（浅蓝表头 + 网格线）、引用、代码块、链接、图片都会保留；**数学公式以矢量图形嵌入**，打印不失真。

> 想临时改纸张或打印份数，还是可以用 `⌘P` 走系统打印面板（里面也能"存储为 PDF"）。

## 主题

**显示 → 主题** 里可以在 MacDown 自带的样式之间切换：

- GitHub 2（默认）
- GitHub 1
- Clearness / Clearness Dark
- Solarized Light / Solarized Dark

选择会被记住，下次打开还是它。

## 支持的语法

表格、围栏代码块、脚注、删除线、下划线、高亮、上标、引用、任务列表、自动链接、SmartyPants 智能标点。

代码块会按语言自动高亮：

```swift
struct Greeting {
    let name: String
    func hello() -> String { "你好，\(name)！" }
}
```

```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b
```

## 数学公式

TeX 公式**默认开启**，四种写法都支持：

- 行内：`\(E = mc^2\)` 或 `$E = mc^2$`
- 独立：`\[ \int_0^1 x\,dx \]` 或 `$$ \int_0^1 x\,dx $$`

效果：

- 行内 \(e^{i\pi} + 1 = 0\)
- 独立：

\[
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
\]

**显示 → 数学公式 (MathJax)** 可以整体关掉；**用 $ 作为行内公式定界符** 可以关掉 `$...$`
（MacDown 默认开着）。关掉 `$` 后 `\\(...\\)` 仍然可用，价格写法如 `$5` 也不会被误判。

代码块里的公式保持原样，不会被渲染。

脚注可以直接用[^1]。
